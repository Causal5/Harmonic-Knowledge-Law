# AI evolution branch

This directory is the operating layer for branch `ai/evolution`. The branch
starts from `main` at `c9e12778aba0014732a8add3c90c5676e5785bf7` and is the
only branch these agents may revise as a standing corpus. `main` remains
human-owned.

- Charter (immutable premise, redefinition bounds): [`CHARTER.md`](CHARTER.md)
- Cycle (one proposal, PR into `ai/evolution`): [`AGENTS/CYCLE.md`](AGENTS/CYCLE.md)
- Work agent: [`AGENTS/work.md`](AGENTS/work.md)
- Adversarial agent: [`AGENTS/adversary.md`](AGENTS/adversary.md)
- Verification agent: [`AGENTS/verifier.md`](AGENTS/verifier.md)
- Ledger: [`LEDGER/index.md`](LEDGER/index.md)
- Changelog for this branch only: [`CHANGELOG.md`](CHANGELOG.md)

Proposals are opened from `ai/proposal/<date>-<slug>` into `ai/evolution`.
Do not open those pull requests into `main`. Charter amendments are only by
Jordan.
