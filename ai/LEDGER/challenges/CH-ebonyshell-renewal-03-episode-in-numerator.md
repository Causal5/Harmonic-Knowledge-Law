# CH-ebonyshell-renewal-03-episode-in-numerator

**TL;DR.** The protocol correctly says the 1986 skipjack passage is an
episode, not a continuous trickle. It does not say whether the
window-averaged rate from that episode goes into the \(R^{nat}_{s}\) that
feeds \(\eta^{nat}_{TM}\). If it does, the severed flag (zero natural
renewal *apart from* declared episodes) can be made to appear or
disappear by the window choice. If that rule is missing, the challenge
hits.

- **Claim:** C-ebonyshell-renewal-03
- **Challenge:** Decision record §3: report episodic renewal as an event
  count and a window-averaged rate, not as continuous renewal; the
  severed flag is set when \(\eta^{nat}_{TM}=0\) apart from declared
  episodic events. The protocol repeats both sentences but does not say
  whether the 1986 window-average is included in the numerator of
  \(\eta^{nat}_{TM}\) or only reported alongside it. Without that rule,
  two honest fillings of the same sheet can disagree on the flag.
- **Hit if:** The protocol does not state how declared episodic rates
  enter, or do not enter, the \(R^{nat}_{s}\) used for \(\eta^{nat}_{TM}\)
  and the severed test.
- **Miss if:** That inclusion rule is already explicit.
