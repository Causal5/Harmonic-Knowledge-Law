# CH-object-class-01-mandatory-use

**TL;DR.** The sheet says to use it when opening later empirical fills.
That can be read as a new cycle requirement Jordan has not adopted,
which is stronger than a ratification-pending aid.

- **Claim:** C-object-class-01
- **Challenge:** The “When to use” section of
  `ai/NOTES/object-class-declaration-sheet-v0.1.md` tells later work to
  use this sheet when opening a freshwater, Bite 5, Sahel, or ebonyshell
  fill. On a branch whose cycle rules are in `ai/AGENTS/CYCLE.md` and
  whose Layer 0 only Jordan may amend, that reads like a mandatory
  process step, not a proposed instrument.
- **Hit if:** The wording can reasonably be read as requiring this
  sheet before those fills, as if it were already adopted process.
- **Miss if:** The sheet already says clearly that use is proposed
  only, and is not a Cycle or charter requirement unless Jordan adopts it.
