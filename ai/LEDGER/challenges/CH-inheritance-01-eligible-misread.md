# CH-inheritance-01-eligible-misread

**TL;DR.** The note says “eligible-as-application” is not empirical
validation and not a registry promotion. The name can still be read as
if the quantity had been approved for general use. If the committed
note does not put an unmistakable warning next to that status, the
challenge hits.

- **Claim:** C-inheritance-01
- **Challenge:** Status vocabulary travels. A later cycle can cite
  “eligible-as-application” as if v0.3.2 had been extended. The
  tightening should say, next to the status list, that these labels are
  unadopted procedure on `ai/evolution` until Jordan ratifies them, and
  that “eligible” never means “validated” or “now a primitive.”
- **Hit if:** That warning is missing or easy to miss.
- **Miss if:** The committed note already makes that unmistakable.
