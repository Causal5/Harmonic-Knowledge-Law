# CH-object-class-02-one-class-only

**TL;DR.** The sheet demands exactly one object class per row. A symbol
such as V can be used as a model construct in one place and as a
computed estimate of a state in another. Forcing a single class can
collapse the distinction the sheet exists to protect.

- **Claim:** C-object-class-02
- **Challenge:** The object-class field says “exactly one.” The sheet
  does not say that two uses of the same symbol must be declared on
  separate rows rather than merged into one class.
- **Hit if:** The committed wording can be read to require a single
  class for a symbol that is used in more than one Layer 0 role.
- **Miss if:** Multiple uses already have an explicit separate-row rule,
  and the four classes remain uncollapsed.
