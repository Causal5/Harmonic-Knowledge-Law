# CH-four-field-02-undefined-terms

**TL;DR.** The four record names are already defined in the 16 October
record and current AEF §2. If this sheet lists them without pointing
at those definitions, a later filler can quietly invent informal
meanings and collapse expenditure into correction.

- **Claim:** C-four-field-02
- **Challenge:** The sheet names allocation, expenditure, achieved
  correction, and side burden, but it does not point the filler to the
  existing 16 October / AEF §2 definitions of those four records. It
  also does not invent definitions here — which is right — so the
  parent pointer is what would keep the terms from drifting.
- **Hit if:** The committed sheet does not cite the parent definitions
  for the four record classes.
- **Miss if:** Those parent pointers are already explicit, and no new
  informal definitions are introduced.
