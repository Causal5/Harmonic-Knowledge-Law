# CH-object-class-02-effort-fields

**TL;DR.** Layer 0 already requires allocation, expenditure, achieved
correction, and side burden to be recorded separately. The sheet can
label a symbol “computed” and still let an effort term mix those four
records.

- **Claim:** C-object-class-02
- **Challenge:** `ai/NOTES/object-class-declaration-sheet-v0.1.md` has
  no field asking, when the quantity is effort-related, which of the
  four 16 October records it is. A filler could declare an “effort”
  observation as computed and still treat spending as correction.
- **Hit if:** The sheet has no required-or-N/A field for allocation /
  expenditure / achieved correction / side burden on effort-related
  quantities.
- **Miss if:** That separation is already a required declaration, or
  clearly N/A for non-effort rows, on the committed sheet.
