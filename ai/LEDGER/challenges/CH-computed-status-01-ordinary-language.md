# CH-computed-status-01-ordinary-language

**TL;DR.** The word “severed” also appears in ordinary life-cycle prose,
not only as the registry flag. If the note is read to ban every use of
that word unless a ratio has been computed, it overreaches and can
gag descriptive writing the Round 7 edit already left in place.

- **Claim:** C-computed-status-01
- **Challenge:** The mussel example still uses “severed” for a life-cycle
  link and for a cross-basin analog. Those are not the registry flag
  assignment in §8 item 3. The note’s scope sentence talks about
  “registry status or flag,” but it never says ordinary-language uses
  of the same word are outside the prohibition.
- **Hit if:** The note can reasonably be read to forbid qualitative
  uses of the same word that are not a computed-flag assignment.
- **Miss if:** That distinction is already explicit.
