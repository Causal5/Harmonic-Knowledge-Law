# CH-inheritance-02-t1-not-a-license

**TL;DR.** Marking freshwater reuse of renewal coverage as
“needs-mapping” is cautious, but it can still be read as permission to
start filling \(\eta_{TM}\) into the Central Valley dictionary this
cycle. The Round 1 official-boundary residuals are still open. If the
note does not say that T1 does not license a computed or filled \(\eta\)
in this cycle, the challenge hits.

- **Claim:** C-inheritance-02
- **Challenge:** needs-mapping is a permission-shaped word. T1 should
  state that no freshwater \(\eta\) is computed or added to the Bite 1
  dictionary here, and that a later mapping is a new proposal, not a
  continuation already authorized by this note.
- **Hit if:** The committed T1 text can reasonably be read as licensing
  a current computed or dictionary use.
- **Miss if:** That bar is already explicit.
