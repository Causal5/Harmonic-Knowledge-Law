# CH-bite5-falsification-02-metric-class

**TL;DR.** The checklist correctly leaves the comparison number blank, but
“any predeclared function of the held-out outcomes” is still wide open. A
filler could lock a metric that ignores most of the named outcomes, or
tweak it after seeing the answer and call it predeclared. If the sheet
does not require a held-out score on the protocol’s named outcomes and
forbid post-hoc metric changes, the challenge hits.

- **Claim:** C-bite5-falsification-02
- **Challenge:** As a falsifiability tightening, Block B still lets the
  comparison metric be any function, so long as it is named before fitting.
  Protocol §6 already names the held-out outcomes (storage, head,
  subsidence, transition-gap, ecological outcomes). The tightening should
  require the locked metric to be a held-out score on that named list, and
  should treat an in-sample or revised-after-the-fact metric as HKL-2.
- **Hit if:** The committed checklist does not constrain the metric to a
  held-out score on those named outcomes, or does not treat post-hoc
  metric changes as a weakening.
- **Miss if:** That constraint is already explicit.
