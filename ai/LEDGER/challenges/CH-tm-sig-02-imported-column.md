# CH-tm-sig-02-imported-column

**TL;DR.** Table 3-1 totals are not a clean protocol \(D_W\) or \(Q_{sw}\) series, because the filing treats groundwater extracted outside the subbasin as a “surface water delivery.”

- **Claim:** C-tm-sig-02
- **Challenge:** The Table 3-1 notes already say imported groundwater from adjacent subbasins is included and is used to calculate pumping. Even if an independent \(C_{irr}\) later appears, the total column still mixes surface supply with imported groundwater. A later summary must not call Table 3-1 totals “delivered surface-water service.”
- **Hit if:** The fill, proposal, or a later summary presents the totals as a pure surface-water delivery or delivered-service series, omitting the imported-groundwater note.
- **Miss if:** Those texts already flag the imported column and treat the table as observations only.
