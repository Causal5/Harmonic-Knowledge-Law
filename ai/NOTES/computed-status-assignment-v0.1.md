# Computed-status assignment procedure v0.1

**TL;DR.** If a status or flag is defined by a computed quantity, a
qualitative story is not enough to assign it. You can still describe
what the case looks like, but you have to say that description is
provisional and leave the official assignment blank until the quantity
is actually computed — or say the evidence is not there.

**Status:** ratification-pending branch note on `ai/evolution`. This is
not a registry amendment, not official vocabulary, and not empirical
validation. The word “procedure” (and any leftover “rule”) is not
adopted registry vocabulary unless Jordan adopts this note. It applies
Layer 0 and the 16 / 30 October records; it does
not add a new primitive or a cutoff.

## Proposed procedure

1. **Computed assignment.** A registry status or flag whose definition
   is a test on a computed quantity (for example, the registry *severed*
   flag, set when \(\eta^{nat}_{TM}=0\) apart from declared episodic
   events) may be assigned only after that quantity is computed on a
   protocol that was locked *before* the series were inspected or the
   assignment was made, or left unassigned. Windows, units, episode
   rule, and sources are part of that lock.
2. **Qualitative narrative.** A source-qualified qualitative description
   may still be written. It must be marked qualitative and provisional,
   and it does not by itself assign the computed status or flag.
3. **Ordinary language.** This procedure covers assignment of a
   computed registry status or flag only. It does not forbid ordinary
   descriptive uses of the same English word (for example, a life-cycle
   link “severed,” or a cross-basin analog) that are not a flag
   assignment.
4. **No invented values.** If the series needed for the quantity are
   missing, the correct result is `needs-evidence` or an unfilled field,
   not a guessed number and not a “so …” assignment.
5. **Scope.** This is a proposed procedure for work on this branch. It
   does not rewrite Registry v0.3.1 or v0.3.2, and it does not promote
   an application quantity into Layer 0.

## What this note does not do

- It does not compute any \(\eta\), \(V\), or Sahel series.
- It does not change the already-reworded mussel §8 item 3.
- It does not decide official Central Valley boundaries or fish-passage
  construction status.
- “Unassigned” is not a finding that the flag is false.
