# Proposal: computed-status assignment rule (Round 8)

**TL;DR.** This cycle writes a short branch rule: if a flag is defined
by a computed number, a qualitative story cannot assign it. The mussel
*severed* flag was the example in Round 7; the same discipline should
apply to later work. No new primitive is added, and no values are
computed.
