# GILN and IIF experimental code archive

Historical example only. Carried over from the [Adversary review on `ai/evolution`](https://github.com/Causal5/Harmonic-Knowledge-Law/blob/19a4aee7f6d5e3952b688dbba376b5cf26c2c849/ai/REVIEW_FOR_JORDAN.md). The Python files preserve the reviewed prototype from [the archived revision](https://github.com/Causal5/Harmonic-Knowledge-Law/tree/19a4aee7f6d5e3952b688dbba376b5cf26c2c849/src).

The prototype records expenditure separately from achieved correction. Undefined scores return `None`. The reviewed revision disables the fixed 90% resource reduction, the connection increment and the weighted HKL-AI score. SRI, HRS and HKL-AI are historical labels in these examples.

The two demonstration entry points are `python test_giln_human.py` and `python test_giln_combined.py` from this directory.
