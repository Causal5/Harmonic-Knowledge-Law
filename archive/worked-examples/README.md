# Archived worked examples

## Central Valley freshwater v0.1

Archived 24 November 2026. The [v0.1 working example](central-valley-worked-example-v0.1.md) predates the Tulare Lake annual pumping and storage comparison. Its regional synthesis also treated groundwater age as a proxy for renewal time and a 2043 delivery scenario as a buffer estimate. The [current worked example, v0.2](../../Release/Examples/central-valley/central-valley-worked-example-v0.2.md) distinguishes those quantities and documents the calendar-year overlap, storage survey seasons and source revisions alongside the annual results. This archive preserves the original file byte for byte.
