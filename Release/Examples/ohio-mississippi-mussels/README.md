# Ohio–Mississippi freshwater mussels

| Document | Status |
|---|---|
| [Worked example](ohio-mississippi-mussels-worked-example.md) | Source-qualified illustration; not an empirical validation or HKL score |

The example traces commercial shell harvest, the 1913 Keokuk dam and its
obstruction of skipjack herring (host fish for ebonyshell and elephant-ear
mussels), dreissenid biofouling, and black carp predation, and asks what
corrective work now substitutes for lost natural renewal. Its central
distinction is that a system can keep visible stock and some function while
losing the pathways that renew it.

The definitions this case motivated are in
[Registry v0.3.2](../../Registry/causal-ethics-master-symbol-registry.md)
([decision record](../../Registry/definition-decisions-2026-10-30.md)), and §8
of the example applies them. The Yangtze material in §8 is a cross-basin
analog, not part of this example's boundary.

**Open empirical steps:** renewal coverage for ebonyshell above and below
Keokuk, if recruitment data exist; monitoring of the planned Keokuk fish
passage as a test of pathway restoration.
