# SLP research and source history

This directory preserves recovered SLP research documents as working or historical material. Statements about compression, thermodynamic benefit, cognition, or implementation completeness remain claims to evaluate. This publication does not supply missing benchmark data or independently verify every citation.

| File | Role |
|---|---|
| [Enhanced SLP / Delta-Self research report](enhanced-slp-delta-self-research-report.md) | Historical architecture and feasibility review |
| [Godel indexing for LLM symbols](godel-indexing-for-llm-symbols.pdf) | Original feasibility-review PDF |
| [SLP framework reconstruction](slp-framework-reconstruction.pdf) | Original PDF recovered under the name `SLP - need complete rework` |
| [SLP WIP copy](source-variants/slp-wip-copy-1.pdf) | Original binary variant of the reconstruction source |
| [SLP WIP original](source-variants/slp-wip-original.pdf) | Another original binary variant |
| [SLP compression with Kanji working copy](slp-compression-with-kanji-working.docx) | Distinct recovered DOCX; preserved alongside the existing repository copy |

The three SLP framework PDFs have identical extracted text, but distinct binary checksums. All are retained to avoid losing source variants. The Kanji DOCX has a different checksum from the [existing repository DOCX](../../Re-use%20SLP%20compression%20with%20Kanji.docx); neither is silently overwritten.

The [SLP harness](../../slp_gdelta_harness/README.md) is prototype code. The [source manifest](../../publication-sources-2026-09-20.json) records exact checksums and recovered filenames.
